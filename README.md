# 📊 Smart Expense Tracker

A lightweight Java web application designed to help users log daily expenses, track monthly budget totals, and visualize category breakdowns interactively.

---

## 🌟 Features
* **User Authentication:** Secure login and sign-up interfaces.
* **Interactive Dashboard:** View total monthly expenditure at a glance.
* **Expense Management:** Add new expenses with categories (e.g., Food & Dining, Entertainment), date, title, and custom notes[cite: 2].
* **Data Visualization:** Built-in category expense breakdown charts[cite: 2].
* **Multi-language Support:** Supports English and Hindi UI localization[cite: 2].
* **Expense History:** Tabular history overview with delete functionality[cite: 2].

---

## 🛠️ Tech Stack
* **Language/Platform:** Java (JDK 8/11/17)
* **IDE:** Apache NetBeans
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** MySQL / PostgreSQL *(Update with your actual DB)*
* **Server:** Apache Tomcat

---

## 🚀 Getting Started

### Prerequisites
* JDK 8 or higher
* Apache NetBeans IDE
* Apache Tomcat Server
* MySQL Database

### Installation & Setup
1. Clone the repository:
   ```bash
   git clone [https://github.com/nakulcodes-code/smart-expense-tracker]
   ```
2. Import the project into **NetBeans IDE**:
   * Open NetBeans -> `File` -> `Open Project` -> Select the repository folder.
3. Database Setup:
   * Create a database named `expense_tracker`.
   * Run the provided SQL script in `database.sql` to import required tables.
4. Update `dbconnection.java` (or equivalent file) with your MySQL username and password.
5. Clean, Build, and Run the project on Apache Tomcat.
